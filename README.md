#### Proyecto microservicios contenerizados en IoT

Objetivo

Este repositorio tiene como objetivo proporcionar una arquitectura de referencia para el diseño, desarrollo y despliegue de microservicios contenerizados orientados a soluciones de Internet de las Cosas (IoT). El proyecto adopta prácticas modernas de ingeniería de software basadas en contenedores, automatización, observabilidad y escalabilidad, integrando principios de seguridad desde el diseño (Security by Design) y enfoques DevSecOps & DataSecOps. Se promueve la optimización del rendimiento, la resiliencia operativa y el uso eficiente de recursos mediante tecnologías cloud-native. Asimismo, se incluyen lineamientos, ejemplos y componentes reutilizables que facilitan la construcción de ecosistemas IoT seguros, mantenibles y altamente disponibles.
